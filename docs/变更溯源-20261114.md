## 1. 问题与根因

- 用户反馈：面板搜索不到 `600000 浦发银行`。
- 实际前端没有独立“股票搜索”接口；添加股票时输入代码，失焦调用 `POST /api/monitors/preflight` 做行情预检，预检失败就表现为“搜不到”。
- 复现：`600000`、`600000.SH`、`sh600000`、`600519`、`000001` 全部报“找不到行情”，说明不是单只股票或代码格式问题。
- 手机容器日志：
  - 东方财富 `push2.eastmoney.com`：`Server disconnected without sending a response.`
  - 新浪 `hq.sinajs.cn`：`403 Forbidden`
- 进一步验证：
  - 手机宿主机访问新浪实时行情成功；容器内新浪 K 线也成功。
  - 原代码所有行情请求共用 `Referer: https://quote.eastmoney.com/`，新浪实时行情要求新浪自己的 Referer，导致 403。
  - 东方财富在手机当前公网出口被断开，并非代码或股票不存在。
  - 腾讯 `qt.gtimg.cn` 在手机容器内可正常返回实时行情。

## 2. 修复内容

| 文件 | 改动 |
| --- | --- |
| `backend/app/quote_provider.py` | `_headers()` 支持按数据源设置 Referer；新浪实时行情改用 `https://finance.sina.com.cn/`。 |
| `backend/app/quote_provider.py` | 新增腾讯实时行情 `_fetch_tencent_quotes()`，解析 `qt.gtimg.cn` GBK 返回，作为东方财富、新浪之后的第三兜底。 |
| `backend/app/quote_provider.py` | 行情兜底顺序改为：东方财富批量 → 新浪 → 腾讯；只对仍缺失的标的继续兜底。 |
| `backend/app/quote_provider.py` | 保留东方财富 K 线 → 新浪 K 线的 MACD 历史数据兜底。 |
| `tests/test_quote_provider.py` | 新增新浪 Referer 校验、腾讯行情解析回归测试。 |

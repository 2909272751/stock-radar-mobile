# 股价雷达

一个跑在 Docker 里的 A 股价格与指标提醒工具。只做监控和提醒，不连接券商、不自动交易。

## 能做什么

- 自选股票/指数，行情按你设置的间隔低频检查
- 支持中文名、拼音首字母、6 位代码搜索，例如输入“浦发银行”即可找到 `600000`
- 价格、涨跌幅、振幅、开盘/最高/最低、昨收、成交量、成交额、换手率、市盈率 TTM 条件
- MA5/10/20/60 均线价格、均线金叉/死叉条件
- MACD DIF、DEA、柱值条件
- 金叉 / 死叉提醒，周期支持日线、周线、月线、年线、60/30/15 分钟
- 行情源全部失败或部分缺失时，面板状态条会明确提示，并发送一次数据源告警
- 同一条规则支持“连续命中 N 次”和“安静时间”，避免重复轰炸
- 提醒进入 SQLite 持久队列，失败自动重试，容器重启不丢
- 企业微信群机器人 / Bark / 通用 Webhook 通知
- 手机优先的响应式面板，支持注册、登录和登录后修改密码
- 交易时段自动检查；非交易时段跳过，节省请求且降低风控风险

## 行情与限频

默认通过东方财富批量行情接口取最新价，同时用同一来源的历史 K 线计算 MACD；东方财富失败时自动切换新浪行情和 K 线，实时行情仍缺失时再使用腾讯行情兜底。

一次检查最多只发一次批量快照请求；只有配置了 MACD 条件时才额外拉取 K 线。建议保持 15 分钟或更长的检查周期。不要把周期调到几秒级，也没有必要。

## 快速启动

```bash
cp .env.example .env
# 可选：设置 LOGIN_USERNAME / LOGIN_PASSWORD 预置首个账号
docker compose up -d --build
```

手机和电脑在同一局域网时，访问 `http://<手机局域网 IP>:18000`。可以直接在“注册”标签创建账号，不需要注册码；也可以用 `.env` 预置的账号登录。

`ALLOW_REGISTRATION=1` 时开放注册，设为 `0` 可关闭注册（只保留已有账号登录）。首次启动时，如果数据库里还没有任何账号且配置了 `LOGIN_USERNAME` / `LOGIN_PASSWORD`，服务会自动预置一个账号；之后修改这两个变量不会覆盖已有密码。忘记密码时请在服务器上直接更新数据库中的密码哈希，或删除 `data/monitor.db` 后重新初始化（会清空自选和提醒记录）。

端口默认绑定到局域网。若要从公网访问，请在反向代理或内网穿透中单独配置，不要把面板端口直接暴露到公网。

## 首次使用

1. 注册并登录后点击“添加股票”，输入中文名、拼音首字母或 6 位代码，例如“浦发银行”或 `600519`。
2. 添加提醒条件。比如“最新价 ≥ 1500”，或“MACD 周线金叉”。
3. 配置通知渠道，点面板上的“发送测试”确认能收到；发送失败的原因会显示在提醒记录里。
4. 设置检查间隔，默认 15 分钟。

## 数据与升级

- 数据：`./data/monitor.db`
- 升级：拉取新代码后 `docker compose up -d --build`
- `data` 目录不要删除；删除会清空账号、自选和提醒记录

## 开发

```bash
python -m pip install -r backend/requirements.txt
uvicorn app.main:app --reload --app-dir backend
```

后台进程：

```bash
python -m backend.app.monitor_worker
python -m backend.app.notification_worker
```

## 说明

行情来自公开行情接口，可能延迟、缺失或调整字段；MACD 按常见 `EMA(12)-EMA(26)`、DEA `EMA(9)`、柱值 `(DIF-DEA)*2` 计算。提醒只是辅助观察，不构成投资建议。

本项目基于开源项目 [a214955582/a-share-monitor](https://github.com/a214955582/a-share-monitor) 二次开发，保留了其 SQLite 存储、规则和通知队列思路，并重写为手机优先的 Docker 部署版本。
